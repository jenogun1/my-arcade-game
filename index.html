1. 키보드 스피드 타자

화면에 출력되는 영문 알파벳(A-Z), 숫자(0-9), 스페이스바를 제한 시간 20초 안에 정확히 타이핑하세요!

최고점: 0

2. 클래식 스네이크

방향키 또는 화면 버튼으로 뱀을 조종해 먹이를 드세요. 벽이나 자신의 몸에 부딪히지 않도록 주의하세요!

최고점: 0

3. 바운스 볼 카운터

화면 안에서 통통 튀어다니는 공들의 정확한 개수를 관찰하여 맞춰보세요. 라운드가 올라갈수록 속도와 수가 늘어납니다!

최고점: 0

4. 메모리 매칭 카드

카드 뒤에 숨겨진 똑같은 그림 아이콘을 찾아 짝을 맞추세요. 적은 시도와 빠른 속도가 높은 점수를 얻습니다.

최고점: 0

5. 빛의 반응속도 테스트

화면 색상이 초록색으로 변하는 순간 신속하게 클릭하세요! 너무 빨리 누르면 부정출발 처리가 됩니다.

최고점: 0

6. 신나는 두더지 잡기

구멍에서 튀어나오는 두더지를 터치하거나 클릭하여 캐치하세요! 제한 시간 30초간 빠르게 누를수록 고득점!
